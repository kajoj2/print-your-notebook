Fonts built into the Typst CLI that the WebAssembly compiler doesn't include.
Source: https://github.com/typst/typst-assets/tree/main/files/fonts

- LibertinusSerif-Regular.otf: SIL Open Font License 1.1
- NewCM10-Regular.otf: GUST Font License

The typewriter fonts (Special Elite, Courier Prime, Cutive Mono) come from `fonts/`
in the repository root, the same ones the CLI uses.
